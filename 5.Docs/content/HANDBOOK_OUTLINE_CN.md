> **产品定位**：帮爱好者把开源机械臂从「能亮」调到「能动」的操作手册  
> **定价**：99 元（早鸟 79 元）  
> **交付形式**：PDF（40–60 页）+ 网盘附录 + 30 天答疑群  
> **版本**：v1.0  
> **关联**：[执行计划](CONTENT_PLAN_CN.md) · [EP01 视频脚本](BILIBILI_EP01_SCRIPT_CN.md)  
> **与架构文档的区别**：`ARCHITECTURE_CN.md` 讲「系统怎么拼」，本手册讲「下一步做什么、看到什么算正常」

---

## 写作总则

1. **每节结构固定**：目标 → 前置条件 → 操作步骤（编号）→ 预期结果 → 若失败 → 相关截图位
2. **截图位用占位符**：`[截图：描述]`，写作时先留位，调试时补图
3. **命令可复制**：CLI 指令、路径、文件名用等宽字体块，直接从你实测环境复制
4. **不讲原理优先讲动作**：原理用 1–2 句带过，细节链到 `ARCHITECTURE_CN.md`
5. **页数控制**：正文 40–60 页，附录不限（网盘交付）

### 3.4 多节点逐个加入策略

**写作要点**：

- **禁止**一上来六轴全接
- 推荐顺序：J1 → J2 → … → J6 → Hand
- 每加一个节点：复测已有节点仍正常

### 3.5 CAN 高频故障表

**写作要点**：

| 现象 | 排查顺序（1→2→3） |
|------|-------------------|
| 完全无 CAN 帧 | 供电、线序、终端电阻、波特率 |
| 偶发丢帧 | 接触不良、线太长、干扰 |
| 只有 Node1 正常 | 串联断路、中间节点拖死总线 |
| 核心板发令无响应 | REF 固件、CAN 初始化、hcan1 绑定 |
